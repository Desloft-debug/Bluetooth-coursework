# Демонстрация принципа работы Bluetooth

Интерактивная 3D-сцена показывает передачу файлов между ноутбуком и телефоном по Bluetooth Classic и получение температуры от датчиков по Bluetooth Low Energy. Можно выбрать направления обмена, запустить несколько потоков и включить потерю пакета с повторной передачей.


## Запуск

1. Скачайте и полностью распакуйте проект.
2. Откройте `app/index.html` в современном браузере с JavaScript и WebGL.
3. Дождитесь загрузки сцены. Если анимация тормозит, выберите **Графика → Экономный**.

Интернет, установка зависимостей и сборка для просмотра не нужны. Сохраняйте папку `app` целиком. Скорость работы зависит от компьютера и браузера.

Если браузер ограничивает открытие локальных файлов, при установленном Python 3 запустите из корня проекта:

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory app
```

Откройте <http://127.0.0.1:8000/>. Для остановки сервера нажмите `Ctrl+C` в PowerShell.

## Управление

1. Выберите не менее двух устройств, включая ноутбук или телефон, и нажмите **Подтвердить устройства**.
2. Настройте направление передачи файлов и получателей температуры. При необходимости включите **Потеря пакета и повтор**.
3. Нажмите **Далее**, затем **Запустить анимацию**.
4. Управляйте просмотром кнопками **Пауза**, стрелками, **Сначала** и скоростью **1× / 2× / 4×**. Кнопка **Настроить** возвращает к параметрам. Пояснения находятся в разделе **Подробности обмена**.

Перетаскивание фона вращает камеру, колесо мыши меняет масштаб. Ноутбук и телефон можно перемещать по столу; датчики закреплены. **Вернуть камеру** восстанавливает ракурс. Щелчок по устройству во время анимации открывает его увеличенный экран.
